What to notice

1. Topic = named stream of records, e.g. orders.

2. Partitions = topic split into ordered logs P0, P1, P2. Different partitions can live on different brokers.

3. Replication = each partition has a leader and optional replicas on other brokers for resilience.

4. Consumer group = consumers share the work; each partition is assigned to at most one consumer in that group at a time.

Note: for this demo, partition choice uses a simple rotating example. Real Kafka normally uses the record key / configured partitioner.

This is a teaching animation. It illustrates the concepts but does not run Kafka, persist real records, or model every delivery/replication setting.
